Compiler for an Imperative Language

Development of a complete compiler implemented in C using Flex and Bison, incorporating lexical, syntactic and semantic analysis, symbol table management and automatic C code generation, for an imperative language designed during the Language Processors course.

The compiler is capable of analyzing programs written in this language, detecting lexical, syntactic and semantic errors and, finally, automatically generating an equivalent C program.

GitHub

Features

  • Lexical analysis using Flex.
  • Syntax analysis using Bison.
  • Semantic analysis.
  • Symbol table management.
  • Support for procedures.
  • Variables and different data types.
  • Lists and list operations.
  • Conditional statements and loops.
  • Automatic C code generation.
