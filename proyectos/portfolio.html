Portfolio Personal

Desarrollo de un portfolio personal desde cero utilizando HTML5, CSS3 y JavaScript, con el objetivo de presentar mi formación, tecnologías, experiencia y proyectos desarrollados durante mi etapa universitaria.

El portfolio está diseñado como una página web responsive, organizada mediante diferentes secciones y páginas individuales para mostrar con mayor detalle los proyectos realizados.

Además, se ha desarrollado una versión en español e inglés para facilitar el acceso al contenido a usuarios de diferentes idiomas.

GitHub

Objetivos

  • Crear un portfolio personal desde cero utilizando tecnologías web estándar.
  • Presentar de forma clara mi formación, conocimientos y proyectos.
  • Desarrollar una interfaz sencilla, moderna y responsive.
  • Organizar cada proyecto en una página independiente con información detallada.
  • Incorporar una versión en español y otra en inglés.
  • Utilizar el portfolio como carta de presentación profesional.

Funcionalidades

  • Navegación entre las diferentes secciones del portfolio.
  • Páginas individuales para cada proyecto.
  • 🇪🇸🇬🇧 Cambio entre las versiones en español e inglés.
  • Acceso a los repositorios de GitHub.
  • Diseño responsive para diferentes tamaños de pantalla.
  • Enlaces internos entre el portfolio y las páginas de proyectos.

Diseño y estructura

El portfolio se ha diseñado utilizando una estructura sencilla basada en diferentes secciones HTML. La página principal funciona como punto de entrada y contiene la información general sobre el perfil, mientras que cada proyecto dispone de su propia página para mostrar información más detallada.

La navegación principal se encuentra situada en una cabecera fija, permitiendo acceder rápidamente a las diferentes secciones de la página.

El diseño utiliza un tema oscuro y una estructura responsive para adaptar correctamente el contenido a diferentes resoluciones y dispositivos.

Diseño responsive

El diseño se ha realizado utilizando CSS para adaptar la distribución de los elementos a diferentes tamaños de pantalla. De esta forma, el contenido puede visualizarse correctamente tanto desde un ordenador como desde dispositivos móviles.

Organización del proyecto

El proyecto se organiza mediante diferentes archivos HTML, una hoja de estilos común, un archivo JavaScript y una carpeta destinada a los recursos y proyectos.

Esta organización permite mantener separada la página principal de las páginas específicas de cada proyecto y facilita la incorporación de nuevos proyectos en el futuro.
