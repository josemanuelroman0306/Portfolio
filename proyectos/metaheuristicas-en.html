Optimization using Metaheuristics

Implementation in C++ of different metaheuristics for solving the Quadratic Knapsack Problem (QKP). The project includes genetic algorithms, memetic algorithms, multi-start search, iterated local search and simulated annealing.

GitHub

Problem

The Quadratic Knapsack Problem (QKP) is a combinatorial optimization problem based on the classical knapsack problem. The objective is to select a set of items while maximizing the obtained profit without exceeding a given capacity.

Unlike the traditional knapsack problem, the QKP also considers the benefit generated by the interactions between pairs of selected items. Therefore, the value of a solution depends both on the individual benefits of the selected items and on the combinations between them.

The problem can be represented using a binary solution, where each position indicates whether an item has been selected or not.

Objective: find high-quality solutions that maximize the total profit while satisfying the knapsack capacity constraint.

Implemented Algorithms

The project implements different search and optimization strategies. These techniques allow different approaches to exploring the QKP solution space to be studied.

Genetic Algorithms

Genetic algorithms use a population of solutions and evolution-inspired operators to explore the search space.

  • AGG - Generational Genetic Algorithm: generational replacement of the population.
  • AGE - Steady-State Genetic Algorithm: partial replacement of the population using newly generated offspring.

Different crossover operators were implemented, including a two-point crossover and a proposed crossover.

Memetic Algorithms

Memetic algorithms combine the global exploration of genetic algorithms with local search techniques to improve the solutions obtained.

  • AM-All: local search is applied to the entire population.
  • AM-Rand: local search is applied to a randomly selected subset of the population.
  • AM-Best: local search is applied to the solutions considered to be of higher quality.

Other Metaheuristics

  • BMB - Basic Multi-Start Search: generation of multiple initial solutions followed by local search.
  • ILS - Iterated Local Search: iterative application of perturbations and local search to explore different regions of the solution space.
  • ES - Simulated Annealing: allows certain worse solutions to be accepted during the search in order to escape local optima.
  • ILS-ES: combination of iterated local search and simulated annealing.

How It Works

The different metaheuristics work with a binary representation of the problem. Each solution uses a vector of zeros and ones to indicate which items are included in the knapsack.

Solution Representation

Each individual is represented using a binary vector. A value of 1 indicates that the corresponding item has been selected, while 0 indicates that it is not part of the solution.

Solution Evaluation

Each solution is evaluated using a fitness function that considers both the individual benefits of the selected items and the benefits resulting from interactions between them.

Constraint Handling

Solutions must satisfy the maximum capacity of the knapsack. When a solution exceeds the available capacity, a repair process removes selected items until the solution becomes feasible again.

Genetic Operators

The genetic algorithms use tournament selection, different crossover operators and mutation to generate new solutions from the existing population.

Local Search

Local search explores neighboring solutions by modifying the selected items in order to find improvements over the current solution.

Perturbation

Algorithms such as ILS introduce controlled modifications to the current solution to escape local optima and explore new regions of the solution space.

Simulated Annealing

The simulated annealing algorithm uses a temperature that progressively decreases to control the probability of accepting moves that temporarily worsen the fitness.

Experimental Analysis

The results show that the size of the instances has a significant influence on both solution quality and execution time. As the number of elements increases from 100 to 300, execution times generally increase across the different strategies.

The tables allow the behaviour of the different variants of genetic and memetic algorithms to be compared, as well as strategies based on local search, simulated annealing, and hybrid methods.

In particular, dividing the results by instance size makes it possible to observe how the behaviour of each strategy changes as the complexity of the instances increases.

Conclusions

  • Implementation of different optimization strategies. The project brings together genetic algorithms, memetic algorithms, and different search-based metaheuristics applied to a combinatorial optimization problem.
  • Balance between exploration and exploitation. The different techniques make it possible to study the balance between exploring the solution space and exploiting promising solutions.
  • Use of local search. Memetic algorithms and ILS incorporate local search mechanisms to improve the solutions found during the optimization process.
  • Application of evolutionary and hybrid strategies. ES and ILS-ES make it possible to analyse, respectively, an evolutionary strategy and a hybrid approach combining iterative local search with an evolutionary strategy.
  • Experimental comparison. The implementation makes it possible to compare different optimization strategies using metrics such as solution quality, number of evaluations, and execution time.
  • Performance of genetic algorithms. The AGG algorithms achieve the highest mean fitness values across the three instance sizes analysed. In addition, the proposed crossover improves the results of the 2-point crossover in AGG, while the opposite occurs in AGE.
  • Performance of memetic algorithms. AM-Best achieves higher fitness values than AM-Rand and AM-All across all three instance sizes, while also maintaining lower execution times than the genetic algorithms.
  • Influence of instance size. Increasing the number of elements from 100 to 300 produces a significant increase in execution time for practically all strategies, demonstrating the impact of problem size on computational cost.
  • Trade-off between solution quality and computational cost. The results show that there is no single strategy that performs best across all metrics. Some techniques achieve higher-quality solutions at the cost of longer execution times, while others provide solutions in considerably less time.
  • Application of Intelligent Computing techniques. The project provides an opportunity to apply different optimization and search techniques to a complex combinatorial problem, reinforcing knowledge of algorithm design, implementation, and experimental evaluation.
