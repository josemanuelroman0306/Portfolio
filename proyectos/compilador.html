Compilador para un lenguaje imperativo

Desarrollo de un compilador completo implementado en C mediante Flex y Bison, incorporando análisis léxico, sintáctico y semántico, gestión de tabla de símbolos y generación automática de código C, para un lenguaje imperativo diseñado durante la asignatura Procesadores de Lenguajes.

El compilador es capaz de analizar programas escritos en dicho lenguaje, detectar errores léxicos, sintácticos y semánticos y, finalmente, generar automáticamente un programa equivalente en C.

Funcionalidades

  • Análisis léxico mediante Flex.
  • Análisis sintáctico mediante Bison.
  • Comprobación semántica.
  • Gestión de tabla de símbolos.
  • Soporte para procedimientos.
  • Variables y distintos tipos de datos.
  • Listas y operaciones sobre listas.
  • Condicionales y bucles.
  • Generación automática de código C.

Ejemplo

El compilador transforma programas escritos en el lenguaje del proyecto a código C completamente funcional. 


Principal {

    entero a;

    Escribe("Hola Mundo");

}

Código generado automáticamente 


printf("Hola Mundo");

Resultado

El compilador genera automáticamente un archivo generated.c, que posteriormente puede compilarse mediante GCC para obtener un programa ejecutable.
