Personal Portfolio

Development of a personal portfolio from scratch using HTML5, CSS3 and JavaScript, with the aim of presenting my education, technologies, experience and projects developed throughout my university studies.

The portfolio has been designed as a responsive website, organized into different sections and individual pages to provide more detailed information about the projects.

In addition, both Spanish and English versions have been developed to make the content accessible to users with different language preferences.

GitHub

Objectives

  • Create a personal portfolio from scratch using standard web technologies.
  • Clearly present my education, technical knowledge and projects.
  • Develop a simple, modern and responsive interface.
  • Organize each project into an individual page with detailed information.
  • Provide both Spanish and English versions.
  • Use the portfolio as a professional presentation.

Features

  • Navigation between the different sections of the portfolio.
  • Individual pages for each project.
  • 🇪🇸🇬🇧 Switching between the Spanish and English versions.
  • Curriculum vitae download.
  • Access to GitHub repositories.
  • Responsive design for different screen sizes.
  • Internal links between the portfolio and project pages.

Design and Structure

The portfolio has been designed using a simple structure based on different HTML sections. The main page acts as the entry point and contains general information about my profile, while each project has its own page to provide more detailed information.

The main navigation is located in a fixed header, allowing quick access to the different sections of the page.

The design uses a dark theme and a responsive structure to properly adapt the content to different screen resolutions and devices.
